# WebMonitoring

A static marketing landing page for a website-monitoring service ("WebMonitorPro").

## Overview

This repository contains a single-page landing site (HTML, CSS, and vanilla JavaScript) that presents a concept for a website-monitoring service: uptime checks, SSL certificate expiry alerts, domain expiry alerts, and Telegram/email notifications. It is a frontend-only, early-stage project - no monitoring backend or check engine is implemented yet, and the page is promotional material rather than a working product.

## Contents

| File | Purpose |
|---|---|
| `index.html` | Landing page markup |
| `styles.css` | Styling and animations |
| `script.js` | Navbar, mobile menu, scroll reveal, and background effects |
| `vercel.json` | Static deployment config for Vercel |

## Running

Open `index.html` in a browser, or serve the directory statically:

```bash
python -m http.server 8000
```

## Status

Early-stage / experimental. The page is deployable as a static site but the monitoring functionality it describes has not been built.
